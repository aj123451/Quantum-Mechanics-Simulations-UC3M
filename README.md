# Quantum-Mechanics-Simulations-UC3M
Simulé el efecto túnel resonante en estructuras de semiconductores de doble barrera simétricas y asimétricas y analicé la convergencia cuántico-clásica de un electrón en un campo magnético cuantizante (Niveles de Landau) para validar el Principio de Correspondencia de Bohr.
